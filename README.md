
# STA 518-01: Statistical Computing & Graphics with R

A comprehensive repository used while studying **STA 518: Statistical Computing & Graphics with R** (Fall 2026) at Grand Valley State University. This project serves as a professional-grade codebase and digital portfolio, documenting advanced workflows in statistical computing, automated data pipelines, and scalable data visualizations using R and the RStudio/Posit Workbench ecosystem.

The primary objective of this repository is to develop, test, and maintain fully reproducible workflows for complex data analysis, algorithmic simulations, and predictive modeling. Each module is structured to demonstrate rigorous engineering standards, clean documentation, and adherence to open-source best practices.

## 📂 Repository Structure

The directory is organized into modular subfolders corresponding to core domains in data science and statistical computing:

*   **`01_Data_Management_and_Cleaning`** – Source code and scripts dedicated to ETL processes, importing, programmatically cleaning, and transforming unstructured, real-world data into tidy, analysis-ready formats.
*   **`02_Exploratory_Data_Analysis_and_Graphics`** – Advanced data visualization projects leveraging the `ggplot2` ecosystem to build elegant, publication-quality graphics and deep-dive numerical summaries for data discovery.
*   **`03_Simulations_and_Randomization`** – Custom-built R programs designed for simulation studies from complex probability models and randomization-based experimental analyses.
*   **`04_Advanced_Statistical_Topics`** – Advanced analytical scripts covering time-series forecasting, randomization statistics, exploratory data mining, and big data analysis frameworks.
*   **`05_Homework_and_Quizzes`** – Structured, reproducible reports authored using Quarto and R Markdown detailing statistical problem-solving and algorithmic implementation.
*   **`06_Final_Project_Portfolio`** – A collaborative, end-to-end data science project evaluating custom real-world datasets, complete with statistical modeling, rigorous methodology, and comprehensive reporting designed to serve as a production-grade portfolio piece.

## 🛠️ Core Competencies & Technologies
*   **Programming & Scripting:** R (Object-Oriented Statistical Programming)
*   **Reproducible Reporting:** Quarto, R Markdown (`.Rmd`), PDF and Word compilation
*   **Data Visualization:** `ggplot2` and associated graphical extension packages
*   **Development Environments:** RStudio Desktop, GVSU Posit Workbench
