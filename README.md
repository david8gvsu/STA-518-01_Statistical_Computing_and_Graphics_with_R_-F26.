STA 518 01: Statistical Computing and Graphics with R (F26)
Welcome to the central repository for STA 518: Statistical Computing & Graphics with R (Section 1, Fall 2026) at Grand Valley State University. This repository serves as an organized digital portfolio and codebase documenting my academic journey, hands-on programming coursework, and mastery of statistical computing using R and RStudio.
The primary objective of this repository is to develop, test, and house reproducible workflows for data analysis, simulations, and data visualization. The directory structure is organized into specific subfolders corresponding to key modular topics outlined in the course curriculum:
•	01_Data_Management_and_Cleaning: Code and scripts focused on importing, cleaning, and transforming messy, real-world data into tidy, analysis-ready formats.
•	02_Exploratory_Data_Analysis_and_Graphics: Data visualization projects utilizing the ggplot2 ecosystem to build elegant, publication-quality graphics and numerical summaries.
•	03_Simulations_and_Randomization: R programs designed for simulation studies from complex probability models and randomization-based experimental analyses.
•	04_Advanced_Statistical_Topics: Coursework exploring advanced analytical methods, including time series tracking, randomization statistics, big data analysis, and introductory data mining.
•	05_Homework_and_Quizzes: Structured Quarto and R Markdown files containing well-documented code solutions for regular programming assignments.
•	06_Final_Project_Portfolio: A collaborative, comprehensive data analysis report evaluating a custom dataset, serving as a cornerstone piece for my professional data science portfolio.
All computational documents within these folders are compiled into clear, well-attributed, and efficient Word or PDF outputs. This repository functions as a testament to my persistent technical growth, problem-solving capabilities, and adherence to rigorous academic integrity and open-source practices in the field of biostatistics and data science.

## 🛠️ Technologies & Tools
