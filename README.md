# STA-518-01_-Statistical-Computing-and-Graphics-with-R-F26-
Repository for STA 518 (Fall 2026) at GVSU. Features organized subfolders exploring statistical computing, data cleaning, and simulations in R. Contains ggplot2 data visualizations, Quarto and R Markdown assignments, and a data science portfolio project focused on solving real-world data problems.
